## Core Question

The user is exploring general techniques to improve DE training of NNs — both
evolutionary-mechanics tweaks and fitness/data design. The sine recurrence is a
testbed, not the target.

## Test Problem

Recurrence:
```text
x[t] = sin(2.5 * x[t-1]) + 0.6 * x[t-2]
```
Input: [a, b] = [x[t-1], x[t-2]]; target: x[t].

Random state-pair data: independent samples from [-2.5, 2.5]^2. Tests function
learning across the full state space, not orbit-fitting.

Default architecture: 2 -> 12 -> 1 (49 weights), cached sigmoid hidden, linear output.

## Techniques That Work

### DE/best/1 — specialized tool for small nonlinear networks
Uses best individual as mutation base vector instead of random. After adding
standard binomial forced-coordinate crossover (`jrand`) and re-baselining,
best/1 is the robust finding: on the 2D pair regression task it improves test
MSE from 0.0342 to 0.00135, about 25x.

Combined with Huber, best/1 remains strong (test MSE 0.00229) but did not beat
plain MSE in the revised seed batch.

DE/best/1 is NOT a general DE improvement:
- Classical benchmarks (Sphere, Rastrigin, Ackley, Griewank): worse than rand/1
  (premature convergence on multimodal functions)
- XOR/parity NN classification: neutral (ties with rand/1)
- NN regression: transformative for small nonlinear networks

### 5D mostly-linear recurrence is genuinely easy
5-input recurrence (20% nonlinear, 113 weights) with rand/1 + huber0.5 achieves
raw test MSE 0.00146 and nMSE 0.00087 in the revised baseline. This uses a
larger configured budget (6.91M evals/run vs 1.73M for pair1), but normalized
error confirms the mostly-linear landscape is easy for rand/1.

## Techniques That Are Marginal Or Confounded

### Huber loss
Huber(delta=0.5): MSE for small errors, linear for large. It looked useful in
the earlier pre-`jrand` batch, but after re-baselining it slightly hurt both
rand/1 and best/1 on the 2D pair task:

- pair1 MSE + rand/1: test MSE 0.0342
- pair1 huber0.5 + rand/1: test MSE 0.0601
- pair1 MSE + best/1: test MSE 0.00135
- pair1 huber0.5 + best/1: test MSE 0.00229

Treat Huber as run-sensitive, not a robust improvement.

### dw1 — distance-weighted loss (8% improvement)
Weight training samples by 1 + alpha * (r / r_max) where r is L2 distance from
origin. dw1 (alpha=1.0) improves test MSE to 0.056. dw2/dw4 overshoot. Does not
additively combine with huber (same mechanism). This is stale from before the
`jrand` re-baseline; rerun before treating it as a live conclusion.

### Depth/width are budget-sensitive
2->12->12->1 (205 weights, deep) with rand/1 achieves test MSE 0.037 — better
than the 2->12->1 baseline (0.054). Width hurts rand/1: 2->24->1 (97 weights)
gets 0.104. These runs also use larger populations and generation counts, so
this is not yet an equal-compute architecture result. Depth may create more
distributed representations and spatial uniformity (1.5x center-corner ratio),
but verify with matched evaluation budgets before treating it as settled.

The revised equal-budget runs show depth and width do not help at the same DE
budget:

- baseline pair1: test MSE 0.0342
- deep-eqbudget: test MSE 0.0579
- wide-eqbudget: test MSE 0.1144

## Techniques That Didn't Work

### Input scaling
Scaling inputs from [-2.5, 2.5] to [-1, 1] makes things 32x worse (test MSE
1.59 vs 0.049). Sigmoid NEEDS input range to create nonlinearity. Starving it
of range makes the network nearly linear.

### LayerNorm
Adds 24 gamma/beta params to the 49-weight network. Test MSE 0.123 (2x worse).
With 2x generations: improves to 0.087 but still trails. DE can't efficiently
optimize the extra params. LN reduces the center-corner error ratio (2.7x vs
10x) but raises the overall level.

### Modern activations (ReLU, GELU, SiLU)
All lose to cached sigmoid in this DE+NN regime regardless of input scaling,
weight bounds, or loss function. Modern activations were designed for deep
gradient-trained networks — they don't transfer to DE-trained small nets.

### Hybrid mutation strategies
curtobest/1 (DE/current-to-best/1) and annealed rand-to-best/1 both sit between
rand/1 and best/1 in performance but never beat the better extreme. No free
lunch: the optimal strategy depends on problem characteristics (parameter count,
nonlinearity).

## Key Insights

1. **Mutation strategy matters most.** After `jrand` re-baselining, best/1 is
   the only robust 2D NN-regression improvement.

2. **The optimal DE mutation strategy depends on the problem.** best/1 for small
   nonlinear regression, rand/1 for classical continuous benchmarks and likely
   larger or more-linear tasks.

3. **Cached sigmoid is the right activation for DE+small-NN.** Modern activations
   (ReLU/GELU/SiLU) don't transfer from gradient-trained deep networks.

4. **Depth/width need more evaluations.** Equal-budget variants are worse than
   the 49-weight baseline; scaled-budget wins should not be read as architecture
   wins.

5. **Region diagnostics are essential.** The center-corner error ratio revealed
   that the bottleneck was spatial coverage, not optimization quality.

## Plain Current-to-pbest/1 Experiment

Implemented JADE-style **DE/current-to-pbest/1** without archive or SHADE-style
parameter memories:

```text
v_i = x_i + F_i * (x_pbest - x_i) + F_i * (x_r1 - x_r2)
```

2D pair task, MSE loss, 49 weights, 1.73M evals/run:

| Task | Test MSE | nMSE | Result |
|------|----------|------|--------|
| pair1 | 0.0342 | 0.0271 | rand/1 baseline |
| pair1-best1 | 0.00135 | 0.00107 | exploitative winner |
| pair1-pbest5 | 0.06018 | 0.04774 | worse than rand/1 |
| pair1-pbest10 | 0.06871 | 0.05450 | worse than rand/1 |
| pair1-pbest20 | 0.06478 | 0.05139 | worse than rand/1 |
| pair1-pbest50 | 0.07097 | 0.05630 | worse than rand/1 |

5D mostly-linear task, huber0.5, 113 weights, 6.91M evals/run:

| Task | Test MSE | nMSE | Result |
|------|----------|------|--------|
| pair5-huber0.5 | 0.00146 | 0.00087 | rand/1 baseline |
| pair5-huber0.5-pbest5 | 0.00186 | 0.00110 | close, but worse |
| pair5-huber0.5-pbest10 | 0.00543 | 0.00322 | worse |
| pair5-huber0.5-pbest20 | 0.13513 | 0.08025 | much worse |
| pair5-huber0.5-pbest50 | 0.15263 | 0.09064 | much worse |

Classical `de_bench quick` result: pbest variants, especially pbest5/pbest20,
recover several cases where best/1 collapses (Ackley/Griewank/Rosenbrock), but
do not preserve best/1's NN-regression exploitation.

Conclusion: plain current-to-pbest/1 is not the desired bridge. It is more
robust on classical functions, but too conservative for the 2D NN regression
where best/1 is the main win. The next strategy to try is **DE/pbest/1**:
use a random top-p% individual as the mutation base,
`v = x_pbest + F * (x_r1 - x_r2)`. That directly tests whether best/1's single
anchor can be diversified without losing the exploitative base-vector behavior.
